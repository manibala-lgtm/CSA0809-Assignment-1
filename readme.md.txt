## Project Description

This project focuses on developing a payment calculator for a village milk co-operative using Python.

The calculator determines the payment for farmers based on milk quantity, fat percentage, and SNF percentage. It also explores Python concepts such as data types, variables, operators, input handling, functions, modules, algorithms, testing, and file handling.

The project uses the `Decimal` module to improve accuracy when handling financial values.

## How to Run the Programs

1. Install Python 3 on your computer.
2. Clone or download this repository.
3. Open the project folder in VS Code or another Python editor.
4. Open the required task folder.
5. Run the Python file using:

```bash
python filename.py
```

For example:

```bash
python task05.py
```

For Task 7 and Task 11, keep the related files in the same folder when running the programs.
